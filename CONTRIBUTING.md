# Contributing

Use Python 3.12 and follow the README quick start to prepare your own local DES export and rebuild the SQLite database.

Before opening a pull request:

- Run the test suite and include the command and outcome in the PR.
- For changes to features or evaluation, explain the observation cutoff, training years, and whether the frozen results are affected.
- Keep raw exports, the populated database, and screenshots containing source yield records out of commits.
- For documentation or dashboard changes, include a short summary and a screenshot when it helps reviewers.

Report reproducibility issues with your Python version, the command you ran, and the first relevant error. Leave out credentials and local user paths.
